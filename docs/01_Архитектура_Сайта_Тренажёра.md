# 💻 Архитектура и возможности веб-тренажёра «Альт Экзамен»

Веб-тренажёр разработан специально для подготовки к сдаче лабораторного практикума по ОС «Альт» (Альт Сервер 10, Альт Рабочая станция 10, Альт JeOS) и сетевой инфраструктуре на базе гипервизора Proxmox VE 8.2.

---

## 🛠️ Технологический стек

* **Frontend:** Чистый HTML5, Vanilla JavaScript (ES6+ Classes), кастомный адаптивный CSS3 (темная тема в стиле Proxmox Dark / Cyberpunk).
* **Независимость:** Не требует установки Node.js, бэкенда или баз данных. Работает локально через протокол `file://` или любой статический веб-сервер.
* **Offline-режим (PWA):** `sw.js` (Service Worker) кэширует все скрипты, шрифты и стили, обеспечивая автономную работу без подключения к сети.
* **Сохранение прогресса:** `localStorage` браузера сохраняет статус выполненных заданий, серии правильных ответов и результаты сдачи экзамена. Предусмотрен импорт/экспорт прогресса в формате `.json`.

## 📑 Разделы и функционал веб-приложения

### 1. 💻 Вкладка «Практика 2–8» (`#sec-terminal`)
* Пошаговый тренажёр, охватывающий **101 практическое задание** с подробным разбором сетевой архитектуры.
* **Интерактивный эмулятор терминала Linux:**
  * Реалистичный вывод команд (`ip -br -c a`, `cat`, `echo`, `ping`, `systemctl`, `vtysh`).
  * **Автодополнение по клавише `Tab`:** реализован полноценный обработчик пути (`/etc/net/ifaces/...`), файлов (`ipv4address`, `options`, `resolv.conf`) и сетевых утилит.
  * **Подсказки и помощь:**
    * `F1` (Подсказка) — текстовое наведение на логику решения.
    * `F2` (Шаблон синтаксиса) — структура команды без готового ответа.
    * `F3` (Ответ) — эталонная команда с возможностью мгновенной вставки.
  * **Разбор «Почему именно так»:** объяснение механизмов работы ОС «Альт» после каждого успешного ввода.

### 2. 🖥️ Вкладка «Стенд Proxmox VE» (`#sec-stand`)
* Симулятор 6 виртуальных машин кластера Proxmox:
  * `10601: ISP` — маршрутизатор интернет-провайдера.
  * `10602: HQ-RTR` — центральный пограничный маршрутизатор.
  * `10603: HQ-SRV` — сервер главного офиса (DNS, DHCP, SSH).
  * `10604: HQ-CLI` — клиентская машина администратора.
  * `10605: BR-RTR` — маршрутизатор филиала.
  * `10606: BR-SRV` — сервер филиала (Active Directory Samba DC).
* Переключение между виртуальными машинами в один клик с автоподстановкой контекста хоста в приглашении командной строки (`root@hq-rtr:~# `).

### 3. 🚨 Вкладка «Аварии & Сценарии» (`#sec-troubleshoot`)
* Режим траблшутинга (поиска и устранения неисправностей):
  * **12 реалистичных аварийных ситуаций** (пропал доступ в интернет после перезагрузки, OSPF застрял в ExStart/Init из-за несовпадения MTU, клиенты не получают IP по DHCP, loopback в resolv.conf написан с ошибкой `=`).
  * Симуляция симптомов сбоя и проверка правильности восстановительных команд.

### 4. ⏱️ Вкладка «Экзамен» (`#sec-exam`)
* **Полная симуляция приёма работы преподавателем:**
  * **Настраиваемый таймер:** выбор между **45 минутами** (рекомендуемый), **60 минутами**, **30** или **15 минутами**.
  * **Цепочка из 14 билетов (Темы 2–8 подряд):**
    Включает в себя последовательную настройку каждого узла и **обязательную проверку работоспособности** (настройка VLAN ➔ проверка тегов; включение NAT ➔ пинг интернета; поднятие GRE ➔ проверка OSPF neighbor в vtysh; настройка DHCP ➔ dhclient на клиенте).
  * Строгий экзаменационный режим (подсказки и ответы выключены).
  * Итоговый протокол: оценка по 5-балльной шкале, процент успеха, затраченное время и детальный разбор допущенных ошибок.

### 5. ⚡ Вкладка «Повторение всех команд» (`#sec-drill`)
* Специальный раздел для экспресс-подготовки перед экзаменом:
  * **37 уникальных команд** без рутинных повторений.
  * Два режима:
    * **Интерактивный ввод** в консоль для закрепления моторной памяти пальцев.
    * **Сводка всех команд списком** с кнопками копирования в буфер в один клик.
  * Фильтрация по конкретным темам (2..8 + контрольные проверки).

### 6. 🎓 Вкладка «Теория и Ответы» (`#sec-defense`)
* **16 ключевых экзаменационных билетов** с готовыми ответами нормальным человеческим языком.
* Режим тренировки: можно спрятать ответ и попытаться сформулировать его самостоятельно, затем нажать «Показать ответ» и сверить ключевые тезисы.

### 7. 🗺️ Вкладка «Карта сети» (`#sec-topology`)
* Интерактивная наглядная схема всей сетевой топологии:
  * Точное отображение физических кабелей, виртуальных мостов Proxmox (`vmbr0` .. `vmbr4`).
  * Раскладка сабинтерфейсов (`enp7s1`, `enp7s2.100`, `enp7s2.200`, `tun0`).
  * Цветовая индикация подсетей и шлюзов по умолчанию.

### 8. 📋 Вкладка «Шпаргалка» (`#sec-reference`)
* **⚡ 2-минутный экспресс-чеклист:** 5 главных проверок работоспособности перед сдачей.
* **📖 Объяснения «Что, Зачем и Почему»:** разбор тем 2–10 простыми словами (MTU 1476, NAT, OSPF MD5, Active Directory, sudoers).
* **📋 Готовые конфигурации для копирования:** эталонные текстовые блоки файлов `options`, `frr.conf`, `dnsmasq.conf`, `sysctl.conf`.
* **⌨️ Тренажёр клавиши Tab:** песочница для тренировки автодополнения длинных путей `/etc/net/ifaces/...`.

## 📱 Оптимизация для мобильных устройств

* **Мобильная панель быстрых клавиш:** кнопки `/`, `-`, `_`, `.`, `=`, `:`, `;`, `~`, `"`, `'`, `>`, `|`, `*`, `Tab`, `Стереть`.
  Позволяет комфортно вводить команды Linux на сенсорном экране смартфона без постоянного переключения раскладок клавиатуры.
* Адаптивная вёрстка под экраны любых размеров: от смартфона до широкоформатного монитора.
