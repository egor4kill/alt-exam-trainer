## 🚇 Тема 6: GRE-туннель и OSPF (FRR vtysh)
| № | Узел | Задача | Команда |
| :---: | :--- | :--- | :--- |
| **20** | Роутеры | Создать каталог GRE-туннеля | `mkdir -p /etc/net/ifaces/tun0` |
| **21** | HQ-RTR | IP-адрес туннеля | `echo '10.0.0.1/30' > /etc/net/ifaces/tun0/ipv4address` |

| **23** | HQ-RTR | Опции GRE-туннеля | `echo -e 'TUNLOCAL=172.16.1.1\nTUNREMOTE=172.16.2.1\nTUNTYPE=gre\nTYPE=iptun\nBOOTPROTO=static' > /etc/net/ifaces/tun0/options` |
| **24** | Роутеры | Запустить демон FRR OSPF | `systemctl enable --now frr` |
| **25** | Роутеры | Проверить соседство OSPF | `vtysh -c 'show ip ospf neighbor'` |
| **26** | Роутеры | Сохранить OSPF-конфиг в файл | `vtysh -c 'write memory'` (или `do wr mem`) |
